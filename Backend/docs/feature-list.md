# 기능 명세서

체크 기준: bean-fable 브랜치 서버 구현, 2026-09-08. 외부 API(인스타그램 조회, AI 추출, 카카오 검색)는 Fake 어댑터다.
사용자 구분은 User 객체 + X-User-Id 헤더(인증은 미구현), 장소는 전역 place + media_place 연결 구조다.

## US-01. 공유로 저장

- [x] 사용자는 Instagram 릴스를 여기담에 공유할 수 있다.
  (POST /media 접수 + 비동기 추출. 공유 확장 UI는 네이티브 몫)
    - [x] 지원하지 않는 링크는 접수하지 않고 사용자에게 이유를 알린다.
      (InstagramUrl 사유별 검증 → 400 + 사유 메시지, ErrorCode 응답 체계 포함)
    - [ ] 로그인 실패 시 사용자에게 로그인 필요 여부를 알린다.
      (User 객체와 user_id 스코프는 구현됨. 진짜 인증(OAuth·401)만 미구현 — task 8)

- [x] 공유한 릴스에서 장소를 추출한다.
  (수집 → 추출 → 매칭 파이프라인 구조 완성, 세 단계 어댑터는 Fake)
    - [x] 접수된 릴스의 장소 추출은 사용자가 앱을 벗어나도 계속 진행된다.
      (@Async 서버 실행, 커밋 후 디스패치)
    - [x] 추출에 성공한 장소는 개수 제한으로 잘라내지 않고 모두 제공한다.
    - [x] 릴스별 장소 추출 성공·실패 여부를 기록한다.
      (Extraction 다형성 상태 + 실패 사유 4종 + 저장 전 검문)

- [x] 사용자는 릴스별 장소 추출 성공·실패 여부를 확인할 수 있다.
  (GET /media 히스토리, 상태 태그·썸네일·제목·날짜)
    - [x] 사용자는 실패한 릴스의 장소 추출을 다시 시도할 수 있다.
      (POST /media/{id}/extraction-retries, 실패 상태에서만, 동시 요청은 조건부 UPDATE로 한 건만)
    - [x] 사용자는 장소 추출에 실패한 릴스를 운영자에게 제보할 수 있다.
      (POST /media/{id}/reports)
    - [x] 사용자는 실패한 원본 릴스로 이동할 수 있다.
      (응답 originalUrl 제공. 열기는 네이티브 몫)

- [x] 사용자는 공유한 릴스에서 추출된 장소를 확인할 수 있다.
  (GET /media/{id} 상세: 장소 개수·목록·decisionStatus)
    - [x] 사용자는 앱에 다시 진입해 공유한 릴스의 처리 상태와 추출 결과를 확인할 수 있다.

- [x] 사용자는 추출된 장소 중 원하는 장소를 저장할 수 있다.
  (POST /media/{id}/place-selections, UNDECIDED → SAVED, decided_at 기록)
    - [x] 여러 장소를 선택하여 저장할 수 있다.
    - [x] 추출된 장소 중 원하지 않는 장소를 선택하여 삭제할 수 있다.
      (POST /media/{id}/place-discards, UNDECIDED → DISCARDED. 버린 장소는 재저장 불가)

## US-02. 장소 다시 보기 (기능 명세 밖이지만 구현됨)

- [x] 지도를 열면 저장한 장소가 전부 핀으로 보인다.
  (GET /saved-places, SAVED 행을 이름·좌표로 묶어 핀 1개로)
- [x] 핀을 누르면 장소 정보와 연결된 원본 릴스 목록이 보인다.
  (GET /saved-places/{id}/media)
- [x] 원본 릴스가 삭제돼도 핀과 장소 정보는 남는다.
  (구조상 충족: 핀 삭제 event는 사용자 저장 해제뿐)
- [x] 사용자는 저장한 장소를 삭제할 수 있다.
  (DELETE /saved-places/{id}, SAVED → UNDECIDED 복귀. DISCARDED로 볼지는 팀 확인 필요)

## 이번 cycle 제외였으나 참조 구현에서 앞당긴 것

- [x] 한 번 추출한 릴스는 재추출하지 않는다.
  (shortcode + processing_version 판정, 완료본 연결 복사. task 10)
- [x] 사용자별 저장·비저장 독립 판단
  (전역 place + media_place 연결, 결정은 연결 행에. task 9)

## 이번 cycle 제외 (남은 것)

- 실패한 릴스에 대한 장소 직접 등록
- [ ] 중복된 릴스는 기존에 추출했던 장소를 삭제하고 새로 장소들을 선택하게 한다.
- [ ] 중복된 릴스로부터 다시 선택된 장소는 상단으로 보여준다.
