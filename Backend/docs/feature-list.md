# 기능 명세서

## US-01. 공유로 저장

- [] 사용자는 Instagram 릴스를 여기담에 공유할 수 있다.
    - [] 지원하지 않는 링크는 접수하지 않고 사용자에게 이유를 알린다.
        - [x] 링크 판별과 사유별 예외 — InstagramUrl·MediaShortcode (ADR-01)
        - [] 접수 거부와 이유 응답 — 접수 Service + Controller + ErrorCode 응답 체계. 도메인을 모두 만든 뒤 웹 계층을 붙일 때 닫는다.
    - [] 로그인 실패 시 사용자에게 로그인 필요 여부를 알린다.

- [] 공유한 릴스에서 장소를 추출한다.
    - [] 접수된 릴스의 장소 추출은 사용자가 앱을 벗어나도 계속 진행된다.
    - [] 추출에 성공한 장소는 개수 제한으로 잘라내지 않고 모두 제공한다.
    - [] 릴스별 장소 추출 성공·실패 여부를 기록한다.
        - [x] 성공·실패 상태와 도메인 규칙을 표현한다.
- [] 사용자는 릴스별 장소 추출 성공·실패 여부를 확인할 수 있다.
    - [] 사용자는 실패한 릴스의 장소 추출을 다시 시도할 수 있다.
    - [] 사용자는 장소 추출에 실패한 릴스를 운영자에게 제보할 수 있다.
    - [] 사용자는 실패한 원본 릴스로 이동할 수 있다.

- [] 사용자는 공유한 릴스에서 추출된 장소를 확인할 수 있다.
    - [] 사용자는 앱에 다시 진입해 공유한 릴스의 처리 상태와 추출 결과를 확인할 수 있다.

- [] 추출에 성공한 장소는 보관함에 자동 저장된다.
    - [] 같은 장소를 다시 저장해도 보관함 행은 중복 생성되지 않고 마지막 저장 시각이 갱신된다.
    - [] 저장된 장소는 해당 공유 이력과 연결된다.
- [] 사용자는 보관함에서 저장된 장소를 삭제할 수 있다.

## 이번 cycle 제외

- 실패한 릴스에 대한 장소 직접 등록

- [] 한 번 추출한 릴스는 재추출하지 않는다.
- [] 이미 추출에 성공한 릴스를 다시 공유하면 기존 추출 결과를 재사용하고 새 공유 이력에 연결한다.
- [] 다시 공유한 장소가 이미 보관함에 있으면 행을 늘리지 않고 마지막 저장 시각을 갱신한다.
