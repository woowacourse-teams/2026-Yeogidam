# 골든셋 정답

`cases.csv` 40건의 정답이다. 정답 장소는 133곳이고, 종류별로 영상 전용 11건, 캡션 9건, 사진 6건, 모음 6건, 장소 없음 8건이다. 모든 정답은 인스타그램 원본(캡션, 댓글, 영상, 사진)과 카카오맵으로 확인했다(2026-10-10). 채점 결과는 `../results/summary.md`에 있다.

## 정답을 정하는 규칙

- 정답은 게시물이 소개하는 먹고 마시는 가게(카카오 분류가 "음식점"으로 시작)의 카카오 장소 ID다. 관광지, 숙소, 행사장, 상품 후기 속 브랜드는 넣지 않는다.
- 같은 이름의 다른 지점은 틀린 답이다. 지점은 게시물이 적은 지번, 도로명, 간판의 전화번호, 사진 속 외관으로 가른다.
- 카카오맵 웹에는 있는데 REST API가 돌려주지 않는 가게는 정답에 두고 `kakao_api_missing_ids`에 표시한다. 금빛돼지 본점(C020), 포플러(C030), 앵치커피(C031) 세 곳이고, 채점에서는 "카카오 API 미제공"으로 따로 세며 이 때문에 성공률의 윗한계는 130/133이다.
- 카카오맵 어디에도 없는 가게는 근처의 다른 가게로 대신하지 않고 정답에서 뺀다. 전남대 후문 노점(C002), 목동 대합수제비(C034), 칙투칙커피스튜디오(C031), 카카오에서 지워진 소쿱 수완점(C030)이 해당한다.
- 종류는 저장할 것을 기준으로 나눈다. 정답이 비면 "장소 없음"이고, 정답이 있으면 장소 이름이 어디에 있느냐로 캡션, 영상 전용, 사진, 모음(장소 3곳 이상)을 나눈다.
